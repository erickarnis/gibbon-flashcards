# Source material

Primary edition: Edward Gibbon, *The Decline and Fall of the Roman Empire*, edited and abridged by Hans-Friedrich Mueller, Modern Library, 2003; eISBN **978-0-307-41976-7**.

## Preserved text

- [Opening passages](mueller-opening.md) and `passages.json`: the unchanged source set for the original opening deck.
- [Volumes I–II](mueller-volumes-1-2.md) and `passages-volumes-1-2.json`: Chapters I–XXVI, through the end of Volume II, preserved from the same local extraction.
- `edition.json`: local extraction provenance, including the original file path and checksums; excluded from Git.

Labels such as **L716** are stable extraction anchors, not printed page numbers. The full extracted text has SHA-256 `76fd65870f1f51ce1676f5831c2091e9b440a1388f5e3be8266a39425a789336`, matching the original provenance. Source transcriptions preserve the supplied wording and editorial omissions. Corrected dates or claims appear in the cards and review notes, never silently in the source text.

The source files cover the **Mueller abridgment**, not material omitted from the complete unabridged work. No new ebook copy or Anki package is included.
