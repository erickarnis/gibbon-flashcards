# Source material

Primary edition: Edward Gibbon, *The Decline and Fall of the Roman Empire*, edited and abridged by Hans-Friedrich Mueller, Modern Library, 2003; eISBN **978-0-307-41976-7**.

- `mueller-opening.md`: passages used by the opening deck, extracted from the reader's supplied edition. Labels such as L716 are extraction anchors, not printed page numbers.
- `passages.json`: the same passages indexed by anchor for quotation checks.
- `editorial-notes.md`: source comparisons, historical decisions, and review history.
- `edition.json`: local extraction provenance, including the original file path and checksums; excluded from Git.

The full ebook remains local and is not included in the repository. Extracted passages preserve the supplied wording; corrections belong in the cards and editorial notes, not in the source transcription.
